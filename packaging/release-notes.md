First public version, Windows only.

Close SteamVR, run `UTMTFTM-Setup` and start SteamVR again. It's the yellow hand in the dashboard. The installer isn't code-signed, so Windows may warn you: click **More info**, then **Run anyway**. The zip is the same program without an installer.

I've used it with Steam Frame and Quest 3 controllers. The others are set up but I haven't tried them on real hardware, so if you try one, please open an issue and say how it went.
